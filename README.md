# ip-01-p5-works · 作业一：创意代码的基本原理（p5.js）

作者：傅亿霞 · 数字媒体艺术

## 作品目录

- **index.html** — 索引页，两个作品的入口
- **static.html** — 《几何构成》（静态）：setup() 中 noLoop()，画面只绘制一次
- **dynamic.html** — 《运动轨迹》（交互动态）：draw() 循环 + 两种交互

## 技术说明

- p5.js（本地库 `libs/p5.js`）
- 《几何构成》在 setup() 里调用 noLoop()，draw() 只执行一次，画面完全静止
- 《运动轨迹》在 draw() 中每帧重绘，圆点阵列用双层 for 循环生成
- 画布不出现滚动条错位（style.css 中 canvas display:block）

## 创作说明

- **《几何构成》（静态）**：粉底上用 for 循环铺出橙 / 米白双圆点阵，前景是黑发、米白脸、深红衣裙的戴眼镜女孩，用矩形、圆和梯形拼出人物，构图对称、有视觉中心。
- **《运动轨迹》（交互动态）**：圆点阵列来回弹跳形成运动轨迹；鼠标左右移动时橙点与白点大小此消彼长；人物眼珠跟随鼠标转动、眉毛随鼠标挑动，操作有即时反馈。

## 配色说明

粉色背景 `rgb(247,160,190)`，橙色圆点 `rgb(242,100,45)`，米白 `rgb(252,238,220)`，
黑色头发 `rgb(0,0,0)`，黄色耳环 `rgb(255,225,0)`，深红衣裙 `rgb(115,15,35)`。
整体为粉 + 橙暖色系，黑与深红做重色对比。
